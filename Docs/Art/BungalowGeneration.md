Generated with built-in image_gen. Each level contains ONE continuous single-storey bungalow, intended footprint 3×1, with veranda inside the original base. Hotel L1 supplied the visual style; bungalow L1 supplied the geometry for every later level. Fixed footprint is visually constrained, not a pixel-identical generated shape.
