# Building upgrade sprite generation

Generated with the built-in image_gen tool using original Level 1 PNG files as edit references. Original assets are unchanged. Levels 2–5 are in `Assets/Shared/Graphics/Art/Detailed/Buildings/`.

All PNGs use a 1536 × 1024 RGBA canvas. Unity importer settings and pixels per unit are inherited from the corresponding Level 1 asset; GUIDs and sprite IDs are unique. The horizontal pivot is inherited; the vertical pivot is corrected to align the foundation edge at the original anchor column, measured at alpha > 128. This compensates for vertical displacement introduced by generation without resampling the images. No scene or prefab references have been changed.

The footprint is constrained through the image edit prompts and checked visually. Generative edits are not a pixel-exact geometric lock; in-scene placement has not been verified in Unity.
