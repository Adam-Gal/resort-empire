# Pool L1–L5 review set

Generated with built-in image_gen using the existing hotel, restaurant and beach bar as style references. Intended logical footprint: 2×2. The L1 full-size basin and square platform are the geometric reference for every subsequent level. No bungalow or spa assets have been generated; work pauses here for user review.

All five PNGs are 1536 × 1024 RGBA and live in `Assets/Shared/Graphics/Art/Detailed/Buildings/Pool/`. Native PNG alpha is preserved. Their front foundation corners define the sprite pivots. Generative outputs follow the fixed-footprint constraint visually, rather than being pixel-identical geometries.
